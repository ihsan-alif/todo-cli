# Todo CLI App
A simple command-line todo application written in Go.
## Features
- Add todo
- List todo
- Mark todo as done
- Delete todo
## Instalation
- git clone https://github.com/ihsan-alif/todo-cli.git
- cd todo-cli
- go mod tidy
## Usage
- go run main.go add "Belajar Go"
- go run main.go list
- go run main.go done 1
